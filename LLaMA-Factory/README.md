# Chiron training backend

Adapted from [LLaMA-Factory](https://github.com/hiyouga/LLaMA-Factory) for joint prediction, measurement, and population supervision.

The Chiron extensions provide the joint data format, measurement-head readout, and measurement loss. Training uses the configuration and entry point in the [parent repository](../README.md#train).
